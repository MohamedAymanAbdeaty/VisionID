University Research Project

VisionID

Real-Time Closed-Set Face-Based Identity Retrieval
using Deep Face Embeddings and Fast Vector Search

SCRFD ArcFace FAISS ONNX Runtime €0 Budget
🏗️

Architecture

Camera → SCRFD Detector → 5-point Alignment → ArcFace Embedding (512-D) → L2 Normalise → FAISS Search → Threshold → SQLite Profile

🔬

Research Question

"How can a face-identity retrieval pipeline be optimised for low-latency search while maintaining recognition quality as the gallery scales?"

📐

FAISS Indexes

  • Flat – Exact, O(N)
  • HNSW – Graph ANN, low latency
  • IVF – Cluster ANN
  • IVF-PQ – Compressed ANN
⚖️

Ethics & Privacy

Closed academic prototype. Uses only synthetic or explicitly consented identities. No real government database. No covert collection.
